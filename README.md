Trazalog Tools Container

## Agentes de IA de Trazalog (rama `develop-v3.5`)

Tres agentes sobre un motor único: **Kuntur** (Coach del administrador), **Quirqui** (Asistente del equipo) y **Faustino** (Entrevistador de expertos). Para industrias extractivas y de proceso: minería, oil & gas y electricidad.
