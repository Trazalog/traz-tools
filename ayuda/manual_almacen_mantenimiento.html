Artículos del Almacén

Gestión de repuestos e insumos

El Maestro de Artículos contiene todos los repuestos, herramientas e insumos que pueden solicitarse en una Orden de Trabajo. Mantenerlo actualizado garantiza que los pedidos de materiales se gestionen correctamente.

1
Menú → Almacenes → Artículos
Accedé desde el menú principal.
2
Clic en Agregar
Se abre el modal de nuevo artículo.
3
Ingresá Código (*) y Descripción (*)
Usá una convención coherente para facilitar la búsqueda posterior.
4
Seleccioná la Unidad de Medida (*)
Ejemplos: unidad, metro, litro, kg.
5
Configurá el punto de pedido (opcional)
El sistema alertará cuando el stock baje de este valor.
6
Activá ¿Lotear Artículo? si corresponde
Permite llevar stocks independientes por número de lote.
7
Clic en Guardar
El artículo queda disponible para pedidos en Órdenes de Trabajo.
✓ TIP
Definí una convención de nomenclatura clara desde el inicio. Ejemplos: REP-001 para repuestos, INS-001 para insumos, HER-001 para herramientas.
02

Cómo funciona el Almacén

Perfil: Supervisor / Planificador / Mantenedor

El almacén de mantenimiento centraliza todos los materiales, repuestos y herramientas que pueden requerirse al ejecutar una Orden de Trabajo. Su correcto mantenimiento asegura que el Mantenedor pueda registrar los insumos utilizados con trazabilidad completa y que el Supervisor tenga visibilidad real del consumo.

Flujo del almacén
1
Alta de artículos en el Maestro
El Supervisor carga los artículos con código, descripción, unidad de medida y punto de pedido.
2
Ingreso de stock inicial
Se registra la cantidad disponible en el almacén para cada artículo dado de alta.
3
Consumo desde la Orden de Trabajo
Al ejecutar una OT, el Mantenedor selecciona los artículos utilizados y las cantidades. El sistema descuenta el stock automáticamente.
4
Alerta de punto de pedido
Cuando el stock cae por debajo del punto de pedido configurado, el sistema genera una alerta para reponer el artículo.
Stock y punto de pedido

Cada artículo en el Maestro tiene dos valores clave:

Concepto Descripción
Stock actual Cantidad disponible en este momento. Se actualiza con cada OT ejecutada.
Punto de pedido Cantidad mínima antes de reponer. Cuando el stock baja de este valor, el sistema alerta al Supervisor.
ℹ INFO
El punto de pedido se configura por artículo al momento del alta o en cualquier momento posterior desde el Maestro de Artículos. Definirlo correctamente evita que una OT quede sin los materiales necesarios para su ejecución.
Gestión por lotes

Cuando se activa la opción "Lotear Artículo" en el alta, el sistema lleva stocks independientes por número de lote. Esto es útil para:

·
Repuestos con número de serie
Permite rastrear exactamente qué pieza fue usada en qué OT.
·
Insumos con fecha de vencimiento
Cada lote tiene su propia fecha, permitiendo consumir primero los que vencen antes (FEFO).
·
Materiales de distintos proveedores
Se puede distinguir el origen de cada ingreso para trazabilidad de calidad.
✓ TIP
Mantener el Maestro de Artículos actualizado es fundamental para que los Mantenedores puedan registrar los insumos con precisión. Se recomienda realizar una auditoría de stock mensual y ajustar el punto de pedido según el consumo histórico de cada artículo.
