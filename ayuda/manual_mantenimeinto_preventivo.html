01

Introducción

Perfil: Planificador / Supervisor

En este apartado explicaremos el proceso completo de carga de Mantenimiento Preventivo en Trazalog Tools. El mantenimiento preventivo permite planificar intervenciones periódicas sobre los equipos antes de que ocurra una falla, reduciendo costos correctivos, extendiendo la vida útil de los activos y garantizando la continuidad operativa.

A diferencia de una Solicitud de Servicio (que reacciona ante una falla), el preventivo es programado con anticipación: el sistema calcula automáticamente cuándo corresponde realizar cada servicio según el período y la frecuencia configurados, y lo presenta al Planificador listo para convertirse en Orden de Trabajo.

Flujo del proceso — visión general
1
Crear el Preventivo
El Supervisor o Planificador carga el preventivo: equipo, tarea, período, frecuencia, duración, herramientas e insumos requeridos.
2
El sistema calcula el vencimiento
Según el período (Diario, Semanal, Mensual, Anual, Horas, km, Ciclos) y la frecuencia configurada, el sistema determina cuándo corresponde realizar el próximo servicio.
3
Aparece en el Calendario del Planificador
En la pantalla de planificación, el preventivo se muestra en verde cuando está listo para generar una OT. El Planificador decide cuándo convertirlo en Orden de Trabajo.
4
Generación de la Orden de Trabajo (OT)
El Planificador selecciona el preventivo, define fecha, hora y tipo de evento (Único o Mensual con cantidad de meses a futuro) y genera la OT.
5
El Mantenedor ejecuta y cierra
La OT es ejecutada por el Mantenedor, quien registra lecturas, tareas, herramientas e insumos, y confecciona el informe de servicio para la conformidad final.
ℹ INFO
El mantenimiento preventivo requiere que el equipo esté previamente cargado en el sistema. Verificá que el equipo al que querés asignar el preventivo exista en el módulo de Equipos antes de comenzar.
02

Crear un Mantenimiento Preventivo

Perfil: Supervisor / Planificador

El primer paso es acceder al módulo de Mantenimiento Preventivo y cargar la información del servicio: a qué equipo corresponde, qué tarea se realizará, y con qué frecuencia debe ejecutarse.

1
Menú → Mantenimiento → Preventivo
Accedé desde el menú lateral izquierdo del sistema.
2
Clic en Agregar
Se abre el formulario de alta de mantenimiento preventivo.
3
Seleccioná el Equipo al que aplica el preventivo
Buscá por código o nombre. El sistema autocompleta los datos del equipo seleccionado.
4
Ingresá el nombre de la Tarea
Describí claramente el trabajo a realizar. Ejemplo: "Limpieza de filtros", "Cambio de aceite", "Revisión eléctrica general".
5
Seleccioná el Período y configurá la Frecuencia
Definí cada cuánto tiempo se realizará el servicio. Ver sección 03 para detalle completo.
03

Período y Frecuencia

Campo obligatorio

El Período define la unidad de tiempo o medida con la que se mide el intervalo del servicio. La Frecuencia indica cuántas unidades de ese período deben pasar entre cada intervención. Juntos determinan exactamente cada cuánto el sistema programará el próximo mantenimiento.

Pantalla — Selector de Período
Trazalog Tools · Campo Período
Campo Período (*): Desplegable con las opciones de unidad temporal o de medida disponibles para el mantenimiento preventivo.
Tipos de período disponibles
Diario
Se ejecuta cada N días. Ej: frecuencia 1 = cada día.
Semanal
Cada N semanas. Ej: frecuencia 2 = cada dos semanas.
Mensual
Cada N meses. Ej: frecuencia 3 = cada tres meses.
Semestral
Cada N semestres (6 meses).
Anual
Cada N años.
Horas ⚡
Habilita Lectura Base y campo Alerta.
Kilómetros ⚡
Habilita Lectura Base y campo Alerta.
Ciclos ⚡
Habilita Lectura Base y campo Alerta.
⚠ CAMPOS CONDICIONALES
Cuando el período es Horas, Kilómetros o Ciclos, el sistema habilita dos campos adicionales:

Lectura Base: ingresá el valor actual del horómetro / odómetro / contador desde el cual el sistema calculará el próximo vencimiento.
Alerta (días): cantidad de días con anticipación en que el sistema avisará del vencimiento próximo del servicio.
Ejemplo práctico
PeríodoFrecuenciaResultado
Mensual3El servicio se realiza cada 3 meses
Semanal2El servicio se realiza cada 2 semanas
Horas500El servicio se realiza cada 500 horas de uso del equipo
Kilómetros10000El servicio se realiza cada 10.000 km recorridos
Diario1El servicio se realiza todos los días
04

Duración y Recursos Humanos

Cálculo de Horas Hombre

Estos campos permiten al sistema calcular automáticamente las Horas Hombre (HH) que demandará cada ejecución del preventivo. Esta información es clave para la planificación de recursos y la estimación de costos de mantenimiento.

Pantalla — Duración, Unidad de tiempo y Operarios
Trazalog Tools · Campos de duración y recursos
HH: 16 — El sistema calcula automáticamente: 8 horas × 2 operarios = 16 Horas Hombre. Este valor se actualiza en tiempo real al modificar cualquiera de los tres campos.
Campos a completar
CampoTipoDescripción
Duración * Requerido Cantidad numérica de tiempo que dura el servicio. Ej: 8
U. de Tiempo * Requerido Unidad de medida del tiempo: Horas o Minutos
Cant. Operarios * Requerido Cantidad de personas necesarias para ejecutar el servicio. Ej: 2
HH (calculado) Auto Horas Hombre = Duración × Cantidad de Operarios. Se calcula automáticamente.
✓ TIP
El campo HH se actualiza en tiempo real. Si ingresás 8 horas y 2 operarios, el sistema mostrará HH: 16 inmediatamente, sin necesidad de guardar.
05

Herramientas e Insumos

Pestañas: Herramientas · Insumos · Adjunto

Una vez completados los datos principales del preventivo, el sistema habilitará tres pestañas para cargar los recursos materiales necesarios para la ejecución del servicio: Herramientas, Insumos y Adjunto.

🔧 Herramientas
📦 Insumos
📎 Adjunto
Pantalla — Carga de Herramientas
Trazalog Tools · Pestaña Herramientas
Ejemplo cargado: Código HLA-MARCA · Marca CAT01 · Descripción MARTILLO-01 · Cantidad 1.
Al ingresar el código, el sistema completa automáticamente la Marca y Descripción de la herramienta.
Cómo cargar Herramientas
1
Hacé clic en la pestaña "Herramientas"
Se habilitará el formulario de carga de herramientas para este preventivo.
2
Ingresá el Código de la herramienta
El sistema buscará automáticamente y completará los campos Marca y Descripción.
3
Ingresá la Cantidad necesaria
Indicá cuántas unidades de esa herramienta se requieren para el servicio.
4
Clic en el botón "Agregar"
La herramienta se agrega al listado inferior. Podés repetir el proceso para agregar más herramientas.
Cómo cargar Insumos

El proceso para cargar Insumos es idéntico al de Herramientas. Hacé clic en la pestaña Insumos y seguí los mismos pasos: código → marca/descripción autocomplete → cantidad → Agregar.

ℹ INFO
Tanto las herramientas como los insumos deben estar previamente cargados en el sistema (Pañol y Almacén respectivamente) para que el autocomplete funcione. Verificá con el área correspondiente que todos los artículos estén dados de alta antes de cargar el preventivo.
Adjuntos — Documentación del procedimiento

En la pestaña Adjunto podés cargar documentación en formato PDF que describa el procedimiento del servicio preventivo. Esto permite que el técnico ejecutor acceda al instructivo directamente desde la Orden de Trabajo.

1
Hacé clic en la pestaña "Adjunto"
Se habilitará el área de carga de archivos.
2
Seleccioná el archivo PDF del procedimiento
Cheklist de inspección, manual del fabricante, protocolo de seguridad, etc.
3
Clic en Guardar para confirmar el preventivo completo
El sistema guarda todos los datos, herramientas, insumos y adjuntos del preventivo.

Cómo generar una Orden de Trabajo desde un Preventivo
1
Abrí la solapa "Preventivo (mes en curso)"
En el panel derecho del calendario verás todos los preventivos listos para ejecutar en el período actual.
2
Hacé clic en el checkbox (✓) del preventivo que querés convertir
Se abrirá automáticamente la pantalla emergente de creación de Orden de Trabajo.
Pantalla — Creación de Orden de Trabajo
Trazalog Tools · Modal "Creación de Orden de Trabajo"
Campos: Fecha y Hora de programación · Tipo de Evento (Único / Mensual) · Cantidad de Meses (solo si Tipo = Mensual).
3
Seleccioná la Fecha y Hora de programación
Definí cuándo se ejecutará esta orden de trabajo.
4
Elegí el Tipo de Evento
Único: genera una sola OT para esa fecha.
Mensual: habilita el campo "Cantidad Meses" para crear OTs programadas a futuro de forma automática.
5
Si elegiste Mensual → ingresá la Cantidad de Meses
El sistema generará OTs para cada mes durante el período indicado. Ej: 6 meses = 6 órdenes de trabajo futuras.
6
Clic en "Generar Orden"
La(s) OT(s) quedan creadas y aparecen en verde en el calendario. Ya están listas para ser asignadas a un Mantenedor.
⚠ IMPORTANTE — Tipo de Evento
Único: genera una OT para la fecha seleccionada. Ideal cuando querés controlar la programación manualmente cada vez.

Mensual + Cantidad de Meses: genera automáticamente OTs a futuro para todos los meses del período indicado. El período entre OTs respeta la frecuencia configurada en el preventivo. Usá esta opción para planificar con mucha anticipación sin intervención mensual.
